# Research OS 工作指令

## 使命

本系统的使命是发现长期控制权资产，而不是追逐短期趋势、新闻刺激或表面增长。

长期控制权资产指能够在复杂系统中掌握瓶颈、控制点或关键供需错配，并能把这种位置转化为持续现金流和资本回报的公司。

## 核心原则

1. 找瓶颈，不找趋势。
2. 找控制点，不只找资源。
3. 找供需错配，不只看需求增长。
4. 优先研究能长期复利的资产。
5. 优先研究复杂系统，因为复杂系统更容易产生误定价。

## 研究流程

```text
宏观 -> 行业 -> 瓶颈 -> 控制点 -> 公司 -> 时机
```

## 禁止事项

- 不从新闻直接推出股票建议。
- 不把短期价格走势当作基本面证据。
- 不忽略反证。
- 不把资源、规模或增速直接等同于控制权。

## 必须记录

- 记录假设。
- 记录证据。
- 记录反证。
- 记录置信度。
- 记录下一步动作。

## 研究目标

本目录是长期控制权研究操作系统。Energy Research OS v0.1 只输出研究判断，不直接输出股票推荐、交易动作或仓位建议。

所有研究都应最终帮助判断：

1. 哪个能源产业层级可能形成未来 10 年控制点。
2. 哪些事实和指标支持或削弱该判断。
3. 哪些假设需要提高、降低或重写置信度。
4. 哪些洞察、假设或控制点候选需要更新。
5. 哪些事实会证明原判断错误。

## 工作原则

- 默认使用中文。
- Markdown 文件是研究事实、判断和决策的源文件。
- 先写结论，再写逻辑，最后写细节。
- 区分事实、解释、假设、判断和投资动作。
- 所有判断都要写出反证条件。
- 不把资料收集当成研究成果。
- 不为了显得完整而加入不能影响决策的内容。

## 信息流

```text
投资信念 -> 分析框架 -> data -> metrics -> insights -> hypotheses -> control-rights -> reviews -> 持续观察
```

## 目录职责

- `beliefs/`：长期投资原则和底层信念。
- `frameworks/`：可复用分析框架和评分方法。
- `industries/`：行业级研究资产。
- `data/`：数据采集层，记录能源行业事实和 weekly signal。
- `metrics/`：指标计算层，把事实转成可比较指标和指标判断。
- `observations/`：原始事实、数据、新闻、财报、政策和调研记录。
- `insights/`：由事实和指标提炼出的可验证判断，使用洞察卡片格式记录假设、证据、反证、置信度和下一步动作。
- `hypotheses/`：假设跟踪系统，维护核心判断、状态、证据、反证和置信度变化。
- `control-rights/`：控制权分析模块，识别未来 10 年电力产业控制点候选，不输出股票推荐或交易动作。
- `reviews/`：研究评审记录，检查事实可追溯性、schema、推理链、反证和研究边界。
- `decisions/`：买入、卖出、观望、仓位调整和复盘记录；Energy Research OS v0.1 暂不使用本目录输出交易动作。
- `agents/`：AI 或研究助手执行任务时使用的工作指令，具体角色和输出规范见 `agents/README.md`。
