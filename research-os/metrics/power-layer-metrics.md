# 电力层级指标

## 结论

电力层级指标用于把单个指标放回产业结构中，判断价值是否从资源层向控制层、知识层或组织层上移。

## 层级指标表

| 层级 | 核心问题 | 关键指标 | 控制权判断 |
| --- | --- | --- | --- |
| generation | 稳定容量是否变稀缺 | renewable_penetration / capacity_utilization / battery_material_price_index | 可调容量和低成本资源可能获得更高系统价值 |
| transmission | 输电能力是否成为瓶颈 | grid_connection_delay / congestion | 输电约束可能转移利润池 |
| distribution | 配电侧复杂性是否上升 | data_center_load_growth / local_load_growth / regional_price_divergence | 高可靠负荷和区域价差可能提高配电侧控制权 |
| dispatch | 调度是否控制复杂性 | peak_valley_spread / day_ahead_realtime_spread / storage_cost_pressure / dispatch_market_reform | 调度层可能获得显性定价权 |
| EMS | 客户是否依赖能源管理系统 | customer_switching_cost / data_feedback_loop / market_volatility | EMS 可能形成组织依赖 |
| VPP | 聚合能力是否变成控制点 | storage_utilization / demand_response / storage_cost_pressure / resource_cycle_rebound / market_volatility | 虚拟电厂价值取决于调度、成本弹性和客户依赖 |
| operations_knowledge | 运维知识是否可复制 | data_feedback_loop / customer_retention | 知识层可能沉淀长期控制权 |
